# Credits

## Nordschleife track data

- **Centre line and corner names:** © OpenStreetMap contributors, available under the
  Open Database License (ODbL) 1.0 — https://www.openstreetmap.org/copyright.
  Source: route relation 38566 "Nürburgring Nordschleife"
  (https://www.openstreetmap.org/relation/38566).
  Only the geometry and way names are used. `src/world/tracks/nordschleife.json` is derived
  from that data (projected to local metres, smoothed, resampled) and is a derivative database
  under the ODbL; the raw download is kept in `scripts/data/nordschleife-osm.json`.
  The rendered track is a Produced Work and carries the attribution
  "© OpenStreetMap contributors" on screen while it is loaded.
- **Elevation:** SRTM 30 m (NASA / USGS, public domain), queried through the OpenTopoData API
  (https://www.opentopodata.org). Cached in `scripts/data/nordschleife-elevation.json`.

Track width, kerbs, grass, guard rails, trees, colliders and all visuals are generated by this
project (`src/world/nordschleife/`, settings in `src/config/tracks.ts`).

## Weather system references

- **Procedural Weather — Three.js Skill** by Kingsley — MIT License
  (https://github.com/CK42BB/procedural-weather-threejs, commit 26ad580). Adapted: the GPU rain
  technique (line segments animated in the vertex shader, wrapped in a box around the camera) →
  `src/world/weather/Rain.ts`; the weather state machine pattern (parameters interpolated towards the
  selected preset). Licence text: `third_party/procedural-weather-threejs/LICENSE`.
- **three.js `Sky` add-on** (Preetham sky with procedural clouds, MIT, part of three.js) — used as the
  sky dome, with weather, night and horizon-fog blending injected into its shader
  (`src/world/weather/SkyDome.ts`).
- Ideas only, no code (neither repository has a licence file, so their code is not used):
  **Three.js Driving Simulator** by sandeshs0 (https://github.com/sandeshs0/threejs-driving-simulator, commit 7302648):
  time / weather turned into smooth signals (sunlit, daylight, golden, overcast), a real solar-position
  formula, road wetness that rises fast and dries slowly, rain slanted by the car's speed, auto / manual
  headlights with a lit-air cone; **Velocity Rush** by prashant371
  (https://github.com/prashant371/velocity-rush, commit 4a760c9): weather-driven light presets and a night star field.
