# Credits

## Nordschleife track data

- **Centre line and corner names:** © OpenStreetMap contributors, available under the
  Open Database License (ODbL) 1.0 — https://www.openstreetmap.org/copyright.
  Source: route relation 38566 "Nürburgring Nordschleife"
  (https://www.openstreetmap.org/relation/38566).
  Only the geometry and way names are used. `src/world/tracks/nordschleife.json` is derived
  from that data (projected to local metres, smoothed, resampled) and is a derivative database
  under the ODbL; the raw download is kept in `scripts/data/nordschleife-osm.json`.
  The rendered track is a Produced Work and carries the attribution
  "© OpenStreetMap contributors" on screen while it is loaded.
- **Elevation:** SRTM 30 m (NASA / USGS, public domain), queried through the OpenTopoData API
  (https://www.opentopodata.org). Cached in `scripts/data/nordschleife-elevation.json`.

Track width, kerbs, grass, guard rails, trees, colliders and all visuals are generated by this
project (`src/world/nordschleife/`, settings in `src/config/tracks.ts`).

## Autobahn references

Ideas only, no code. Neither repository has a licence file, so nothing was copied from them; the Autobahn
(`src/world/autobahn/`) is written for this project.

- **nightdrive** by StarKnightt (https://github.com/StarKnightt/nightdrive, commit 9b918ae): the road as a pure
  function of distance with an incrementally integrated centre line, ribbon chunks streamed around the player,
  terrain carved to the road with an apron, instanced vegetation kept off the road.
- **Three.js Driving Simulator** by sandeshs0 (https://github.com/sandeshs0/threejs-driving-simulator,
  commit 7302648): features as spans along the road (hill mass over a tunnel, ravine under a bridge), a chunk as a
  slice of the world, small vertical offsets to stack markings over asphalt, guard rails built per chunk.

Signs use fictitious destinations; the styling follows the public German road-sign conventions (blue motorway
panels, round speed signs).

## Infinite Autobahn world references

- **Procedural Terrains** by ZyFou — MIT License (https://github.com/jorgefsb/proceduralterrains,
  commit 3289c4b). Approach followed, own TypeScript code (no code copied; the licence text is kept in
  `third_party/procedural-terrains/LICENSE`):
  - several slow "climate" noise fields turned into soft, overlapping biome weights (`climateAt` /
    `biomeWeightsAt`) → `src/world/autobahn/BiomeMap.ts`
  - ridged fractal noise where each octave is weighted by the previous one (`ridgedFBM`) →
    `src/world/autobahn/noise.ts`
  - terrain chunks in LOD rings around the camera, skirts to hide level seams, a radial,
    time-budgeted build queue (`InfiniteWorld`, `ChunkStreamScheduler`, `buildChunkGeometry`) →
    `src/world/autobahn/TerrainTiles.ts`
- **nightdrive** by StarKnightt (no licence, ideas only, commit 9b918ae): nested terrain rings around the
  camera coordinated with a road corridor, distant ranges masked away from the road, vegetation kept off
  the corridor → `TerrainTiles.ts`, `TerrainField.ts`, `DistantScenery.ts`.

## Traffic models

- Car following: the **Intelligent Driver Model** (M. Treiber, A. Hennecke, D. Helbing, "Congested traffic
  states in empirical observations and microscopic simulations", Phys. Rev. E 62, 2000).
- Lane changes: safety / incentive checks in the spirit of **MOBIL** (A. Kesting, M. Treiber, D. Helbing,
  "General lane-changing model MOBIL for car-following models", Transportation Research Record 1999, 2007).
- Own implementation in `src/traffic/`; traffic vehicles are simple procedural models (no third-party assets).
